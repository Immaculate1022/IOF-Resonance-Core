## 🌐 Overview
PegaConstellation is a unified ecosystem for high-dimensional physics research, self-reflective AI, and advanced cybersecurity. Built on the **Infinite Optical Fabric (IOF)** framework, it integrates academic research with production-grade software and systems philosophy.

## 🚀 Core Components

### 1. Aetherius Nexus
- **Type**: Physics Research Platform (SaaS)
- **Features**: 3D Simulators, Theory Library, AI Assistant
- **Stack**: React, Node.js, Express, Drizzle ORM

### 2. IOF Design Grammar
- **Type**: Systems Philosophy Framework
- **Purpose**: Guide for building transparent, coherent, and ethically-governed systems.

### 3. AHR-Endpoint
- **Type**: Ransomware Defense System
- **Features**: Sub-2s Global Containment, Ephemeral Invariants, NATS Propagation
- **Stack**: Rust, NATS, React/Node.js Management Console

### 4. Möbius-Llama
- **Type**: Self-Reflective AI Architecture
- **Features**: Golden-Ratio Decay, Universal Adapter, Adaptive Computation Time
- **Compatibility**: Llama, Mistral, Qwen, Gemma, Phi, Falcon, etc.

## 📂 Ecosystem Infrastructure
The project is organized into 8 specialized GitHub repositories:
- `aetherius-nexus`
- `iof-design-grammar`
- `moebius-llama`
- `ahr-endpoint`
- `community` (Governance & RFCs)
- `docs` (Central Documentation)
- `research` (Academic Publications)
- `pegaconstellation-hub` (Unified Platform)
